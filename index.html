Dungeon do Código

Cole código C ou abra um arquivo .c. Cada função vira uma sala: quanto mais complexa a função, maior e mais perigosa a sala. Ande com as setas ou WASD para explorar.

Processado localmente no seu navegador. O aplicativo não envia, salva em armazenamento persistente nem executa seu código.

Experimente com o código já carregado, cole o seu ou abra um arquivo .c.

Cole ou abra até 512 KiB de código C. Limite de 64 funções e 256 relações de chamada.

Funciona melhor com funções simples, sem structs aninhadas complexas

código → função → sala
int main() { processar(); }   void processar() { if (...) { for (...) { ... } } }
→ main() chama processar(): duas salas conectadas por um corredor.

O analisador identifica as funções e transforma cada uma em uma sala. Mais estruturas de controle aumentam a complexidade e o perigo.
