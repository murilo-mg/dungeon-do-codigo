# Fontes locais

As mesmas famílias e pesos usados na interface anterior foram obtidos da
distribuição oficial Google Fonts e convertidos de TTF para WOFF, sem alterar
os glifos. A página não consulta Google Fonts em tempo de execução.

- Cinzel: pesos 600 e 700, distribuição v26.
- JetBrains Mono: pesos 400, 500 e 700, distribuição v24.

As licenças SIL Open Font License 1.1 estão nos arquivos `OFL-cinzel.txt` e
`OFL-jetbrainsmono.txt`. A conversão de formato não muda os nomes das famílias.

Origem das licenças:

- https://github.com/google/fonts/tree/main/ofl/cinzel
- https://github.com/google/fonts/tree/main/ofl/jetbrainsmono
